# OneNote Clone - 웹용 앱

## 기능
- 최근 페이지 / 전자 필기장 목록
- 소속기관 등록 → 구역(섹션) → 페이지
- 페이지 상단: 오늘 날짜 + 제목 한 줄, 구분선
- *** 수정하기 → 일일체크리스트 (사각 체크 + 취소선)
- 에디터: 커서 위치 이미지 삽입 (우클릭), 리사이즈 핸들, 50/75/100% 버튼, Enter로 계속 입력
- 백업 받기 / 복구: Excel(.xlsx) 5시트 + JSON 완벽 복구

## GitHub Pages 배포
1. 이 폴더 파일 전체를 GitHub repo에 업로드
2. Settings > Pages > Source: Deploy from a branch, main / root
3. https://USERNAME.github.io/REPO/ 접속

로컬: index.html 더블클릭
